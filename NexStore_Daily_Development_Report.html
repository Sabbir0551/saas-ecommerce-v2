01 Dedicated Merchant Profiles & Deep-Dive Command Modal

A multi-tabbed command interface was implemented inside the Super-Admin Command Portal allowing granular, store-by-store management across all 28 registered tenant merchants.

Management Tab Features & Architectural Capabilities Primary Controls & Fields
1. Subscription & Billing Real-time active days counter, renewal countdown, plan tier switching, payment ledger. Starter (1.5k), Growth Pro (3.5k), Enterprise (8.5k), Add Invoice Form, Status toggle.

02 Merchant Self-Service "Subscription & Limits" Portal

Merchants can now monitor their platform quotas and billing transparency directly from the merchant dashboard (/admin/dashboard?tenant=smartvolt).

Live Usage & Quota Telemetry Meters
REAL-TIME DB SYNC
  • Product Catalog Meter: Displays active products vs allowed quota (e.g., 9 / 500 items used on Growth Pro).
  • Monthly Order Meter: Tracks volume against plan allowances (e.g., 2 / 1,500 monthly transactions).
  • Staff Access Meter: Monitors provisioned team logins against plan caps (e.g., 1 / 5 staff members).
  • Database Partition: Visualizes isolated PostgreSQL JSON schema partition health for high throughput.
  • Feature Entitlements Checklist: Visual green badges for active entitlements and lock badges for restricted features.
  • Upgrade Request Channel: Merchants can directly submit custom feature demands to Super-Admin.

03 Backend Architectural Security Gates & Quota Enforcement

Server-side validation checks were introduced to prevent unauthorized API utilization, resource exhaustion, and suspended account activity.

Module & Route Enforcement Condition Error / Restriction Action
catalog.routes.ts Subscription status is suspended or current product count ≥ features.maxProducts Returns 403 Forbidden preventing new catalog additions.
order.routes.ts Consignment dispatch called when features.courierLogisticsAPI === false Blocks Steadfast / Pathao API dispatch and prompts merchant to upgrade plan.
tenant.routes.ts Custom CNAME domain assigned when features.customDomain === false Restricts branded domain pointing and preserves fallback subdomain.
